EVIDENCE FROM THE CORPUS

Semantic findings

Design description and findings

The 2023–2024 DKU bulletin was parsed into paragraphs and short course or policy blocks, preserving formal headings and printed page references. Front matter, contents pages, small-print footnotes, table fragments, duplicates, and blocks shorter than twenty words were excluded. Exceptionally long blocks were split at sentence boundaries. This creates an exploration of substantive prose rather than an exhaustive transcription of every table. Each passage was embedded with all-MiniLM-L6-v2, using attention-mask mean pooling and L2 normalization. Longer inputs were encoded in token windows and combined by token count, preventing silent truncation. UMAP projected the original 384-dimensional vectors into two dimensions using cosine distance, fifteen neighbors, minimum distance 0.15, and seed 401. K-means formed eight topics in the original embedding space with ten initializations and the same seed. Labels were assigned after inspecting centroid-near passages and characteristic TF-IDF terms. The D3 map represents each passage as a point: position reflects UMAP, color indicates topic, and circle area represents passage length. A neighboring matrix uses color intensity for passage counts within formal sections and topics. Clicking a matrix cell highlights matching map passages; selecting a point outlines its matrix cell and opens persistent details. Search and section/topic filters combine, while zoom and pan support local inspection. Five cosine-nearest passages expose connections across formal boundaries. The findings above quantify dominant topics, cross-section coverage, section diversity, and related passages. Course descriptions strongly influence this corpus. Topic labels are interpretive, and neither map distances nor cluster boundaries should be treated as definitive classifications.
