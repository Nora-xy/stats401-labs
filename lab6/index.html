Binary: like cutting a sheet into two groups with roughly balanced GDP totals, then cutting each group again. Cuts are proportional to the groups’ GDP, so they need not be equal halves. The region shades match the first map.

Design description

I use distinct hues for continents to make the largest geographic groups easy to identify. Each continent contains non-overlapping region rectangles, which contain country rectangles. Country area encodes GDP, allowing approximate comparisons within each view; gaps and label space affect the visible areas. Separate ↑, =, and ↓ markers encode GDP status in both maps, and tooltips provide exact values.

In both maps, I vary lightness within each continent’s hue to distinguish regions. The same region keeps the same shade across maps, making it easier to follow groups when their positions change. These shades identify categories, not higher or lower GDP. Borders and labels reinforce the hierarchy where similar shades are difficult to distinguish.

Squarify packs rectangles into rows while favoring shapes close to squares, which often helps labels fit. Binary subdivision repeatedly divides space into two groups with roughly balanced GDP totals, producing a different arrangement. These cuts can separate countries within a region, so they do not always indicate regional boundaries. Both methods preserve the same geographic nesting. Keeping colors, data, canvas size, and padding consistent makes the effect of the subdivision method easier to compare; neither method is assumed to be universally more readable.
